# TravelStat ✈️

Cross-platform mobile prototype (Android + iOS) for tracking visited countries and cities, recording trips with budgets, attaching travel media, and visualizing personal travel stats.

**Offline-first. No accounts. All data lives on-device.**

## Status

Pre-iteration: design approved, implementation plan in progress.

- Design spec: [`docs/superpowers/specs/2026-05-18-travelstat-design.md`](docs/superpowers/specs/2026-05-18-travelstat-design.md)
- Android APK releases will appear on the [Releases page](https://github.com/irakliygotsiridze-cmd/tre/releases) after each iteration validation gate passes.
- iOS release pending Apple Developer account.

## Stack

React Native · Expo (managed) · TypeScript · react-native-maps · expo-sqlite · Zustand · React Native Paper · React Navigation (Drawer).

## Development

```bash
npm install
npx expo start          # then scan QR with Expo Go on a physical device
```

Datasets (countries.geojson, cities.json, etc.) are generated by `scripts/build-data.ts` and committed into `assets/data/`.
